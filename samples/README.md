# Samples

- `loft.nodecraft` — Loft → Shell → Transform → Edge workflow.
- `large-perforated-plate.nodecraft` — larger boolean/perforation graph.
- `solidcamera.nodecraft` — camera sketch graph; do not treat as scratch.

These are user-facing example documents, not generated build artifacts.
- `gigatest-forest-5000.nodecraft` — 5,000-node forest stress document: 624 explicit trees with mixed shapes/scales, stratified random scattering, landscape and output.
